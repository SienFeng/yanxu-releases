# 言序 Yanxu — 安装包发布

言序是一个实时面试表达辅助工具：听清面试官的问题，帮你组织可以口述的回答。

这个仓库**只用于发布安装包**，不包含源代码。请在 [Releases](https://github.com/SienFeng/yanxu-releases/releases) 页面下载最新版本。

## 系统要求
- macOS 14.2 及以上，Apple Silicon（M 系列芯片）
- Windows 版本计划中

## 安装（macOS）
1. 下载 `Yanxu-<版本>-arm64.dmg`，打开后把 Yanxu 拖到“应用程序”文件夹。
2. 目前的安装包没有经过 Apple 公证：第一次打开时请在“应用程序”里**右键点 Yanxu → 打开**，再在弹窗中点“打开”。
3. 需要采集面试官的声音时，在“系统设置 → 隐私与安全性 → 录屏与系统录音”中允许 Yanxu。

## 更新
v0.3.1 起，应用会自动检查这个仓库的新版本：左下角版本号旁出现“有新版本”时，点开即可下载、校验并安装，也可以回退到最近的旧版本。

安装后如果无法采集声音，请在“录屏与系统录音”中删除旧的 Yanxu 条目后重新添加（未公证应用的限制）。

## 校验
每个版本的发布说明中列出了安装包的 SHA-256；应用内更新会自动校验。
